# 관리자 패키지 지침

이 파일은 `src/main/java/com/igmo/admin/` 하위 관리자 기능에 적용한다.
상위 `AGENTS.md`, `src/main/java/AGENTS.md`, `src/test/java/AGENTS.md` 지침도 함께 따른다.

## 책임과 의존성 경계

- `admin`은 운영 기능과 분리된 관리자 도구를 담당한다.
- 운영 코드에 직접 의존해야 한다면 구현체가 아닌, 목적이 분명한 최소 계약만 사용한다.
- 관리자 정책과 운영 정책을 하나의 서비스에 조건문으로 섞지 않는다.
- 현재 요구사항에 없는 공용 인터페이스, 추상화, 설정 옵션은 추가하지 않는다.

## 보안과 설정

- 관리자 기능의 인증·인가 요구사항을 우회하지 않는다.
- 비밀번호, API 키, 토큰, 외부 시스템의 민감한 오류 정보를 로그·응답·UI에 노출하지 않는다.
- 새 환경 변수를 추가하면 `application.yaml`과 `.env.example`을 함께 갱신한다. `.env`는 읽거나 수정하지 않는다.

## 테스트와 검증

- 관리자 Java 코드를 변경하면 같은 변경 단위의 테스트를 `src/test/java/com/igmo/admin/`에 반드시 추가하거나 수정한다.
- 단위 테스트로 성공 경로와 변경한 오류·정책 경계를 검증한다.
- 단위 테스트로 충분하면 Spring Context를 띄우지 않는다. 테스트 규칙의 상세는 `src/test/java/AGENTS.md`를 따른다.
- UI 코드만 변경한 경우에는 테스트 추가가 필수는 아니다. 다만 UI와 함께 API 계약을 변경하면 API 테스트를 추가한다.
- 코드 변경 후 영향 범위의 테스트를 `./gradlew test --tests ...`로 실행한다.
