# Igmo : AI 이미지로 프롬프트 추측하기 게임

## 🛠️ 1. 구체적인 서비스 아이디어 & 게임 룰

이 게임은 "AI가  그린 그림을 보고 프롬프트를 추측하여 원본 프롬프트를 맞추는 게임"입니다. 디스코드나 보이스 채널을 켜고 친구들끼리 플레이할 때 최고의 재미를 보장합니다.

### 1.1. 화면 목록

1. 메인화면
    1. 새 게임 : 닉네임 입력, New Game
    2. 참여하기 : 닉네임 입력, 방 코드 입력, Join
    3. 데모/영상 소개
2. 대기방
    1. 게임 코드
    2. 대기열 및 점수보드, 시작버튼(비활)
    3. 프롬프트 입력, 제출 버튼
        1. 대기열에서 준비 완료 표시해주고, 내 그림 보여주고, 모두 준비되면 시작 버튼 활성화
    4. 게임 시작
        1. 대기열에서 누구 차롄지 보여주고, 일반 참가자들은 프롬프트를 입력할 수 있음, 타이머가 지나가야돼
            1. 다른 사람이랑 프롬프트가 너무 똑같으면 제출 못하게 함.
            2. 모두 투표 완료하면 점수 보여줌, 옆에 대기열에도 점수 반영
        2. 출제자의 경우 그냥 보고만 있음

### 1.2. 인게임 플레이 루프 (총 4단계)

```
[1단계: 출제 및 생성] ──> [2단계: 가짜 오답 제출] ──> [3단계: 대혼돈의 투표] ──> [4단계: 결과 및 점수]
```

- 1단계: 제시어 출제 및 이미지 생성 (제한 시간 30초)
    - 시스템이 라운드마다 한 명의 '출제자(아티스트)'를 지정합니다.
    - 출제자가 자유롭게 한국어 프롬프트를 입력하면, 백엔드에서 AI API를 호출해 단 1장의 이미지를 생성한 후 방에 있는 모든 유저에게 보여줍니다.
- 2단계: 진짜 같은 가짜 프롬프트 제출 (제한 시간 45초)
    - 출제자를 제외한 나머지 플레이어들은 생성된 이미지를 보고, "출제자가 AI에게 뭐라고 명령해서 이 그림을 뽑았을까?" 유추합니다.
    - 유저들은 다른 사람들을 완벽히 속이기 위해 진짜 같은 '가짜 한국어 프롬프트(오답)'를 제출합니다.
- 3단계: 대혼돈의 투표 (제한 시간 30초)
    - 화면에 `[출제자가 입력한 진짜 프롬프트 1개] + [플레이어들이 제출한 가짜 프롬프트 N개]`가 보기로 섞여서 출력됩니다.
    - 출제자를 제외한 모두가 "이 중 진짜 프롬프트는 무엇인가?" 투표합니다. (자기가 낸 오답은 투표 불가)
- 4단계: 결과 공개 및 점수 정산
    - 낚시 점수: 다른 유저가 내가 제출한 '가짜 프롬프트'에 투표했다면? (낚은 사람 * +1점) (가장 중요한 트롤링 요소)
    - 정답 점수: 진짜 프롬프트를 맞춘 사람 (투표수 * +2점)
    - 출제자 점수: 투표한 사람이 1명이라도 있으면 출제자도 (투표수 * +2점) (아무도 투표하지 않거나 모두가 투표하면 0점 -> 적당히 난해하고 적당히 직관적이게 프롬프트를 짜야 함)

## 🚀 2. 시장 경쟁력 (왜 한국어 버전이 먹힐까?)

### "번역의 늪" 해결 (백엔드 프롬프트 엔지니어링)

일반적인 해외 AI 게임에 한국어를 넣으면 번역기를 대충 거치기 때문에 디테일이 뭉개집니다.

- 우리 서비스는 한국어 특화로 이미지를 생성합니다.

---

## 🎯 3. 서비스 성공을 위한 핵심 엣지 (Feature)

1. 로그인 없는 간편한 시작 (익명 입장): 닉네임만 입력하고 방 만들어서 링크 공유하면 바로 시작할 수 있는 웹 기반 아키텍처 (UX 허들 최소화).
2. 한국어 프롬프트로 이미지 생성: 한국어 프롬프트로 작성자가 의도한 그림을 생성. 정확도와 속도가 중요.
3. 짤방 다운로드 및 공유: 라운드가 끝나면 `[생성된 이미지 + 1등 프롬프트 문구]`가 합쳐진 커스텀 카드(짤방)를 만들어 주어, 인스타그램 스토리나 커뮤니티에 쉽게 공유(바이럴)할 수 있도록 지원.
4. 수위 및 악성 필터링 (Moderation): 유저들이 실시간으로 텍스트를 마구 입력하는 파티 게임 특성상 욕설, 비하, 음란 프롬프트를 차단하는 한국어 욕설 필터링 딕셔너리와 OpenAI Moderation API를 백엔드 단에 이중 안전장치로 배치.
