# Igmo : AI 이미지로 프롬프트 추측하기 게임

## 🛠️ 1. 구체적인 서비스 아이디어 & 게임 룰

이 게임은 "AI가 그린 그림을 보고 프롬프트를 추측하여 원본 프롬프트를 맞추는 게임"입니다. 디스코드나 보이스 채널을 켜고 친구들끼리 플레이할 때 최고의 재미를 보장합니다.

### 1.1. 화면 목록

1. 메인화면
    1. 새 게임 : 닉네임 입력, New Game
    2. 참여하기 : 닉네임 입력, 방 코드 입력, Join
    3. 데모/영상 소개
2. 대기방
    1. 게임 코드
    2. 대기열 및 점수보드
    3. 준비 완료 버튼
    4. 모두 준비 완료 시 이미지 준비 단계로 이동
3. 이미지 준비 화면
    1. 각 플레이어가 프롬프트 입력
    2. AI 이미지 생성
    3. 생성된 내 이미지 확인
    4. 모든 플레이어가 이미지를 생성하고 3초간 확인하면 게임 시작
4. 게임 화면
    1. 현재 라운드의 출제자와 이미지 표시
    2. 일반 플레이어는 원본 프롬프트 추측 제출
        1. 다른 사람이랑 프롬프트가 너무 똑같으면 제출 못하게 함.
    3. 모든 추측 제출 완료 시 투표 진행
    4. 모두 투표 완료하면 결과와 점수 공개
    5. 다음 라운드 진행
    6. 모든 라운드 종료 시 최종 점수 공개

### 1.2. 인게임 플레이 루프

```
[이미지 준비] ──> [라운드 진행] ──> [최종 결과]
```

#### 1단계: 이미지 준비

- 로비에서 모두가 준비 완료를 하면 이미지 준비 단계로 진입합니다.
- 각 플레이어는 자유롭게 한국어 프롬프트를 입력합니다.
- 백엔드는 각 플레이어의 프롬프트로 AI 이미지를 생성합니다.
- 각 플레이어는 생성된 자신의 이미지를 확인합니다.
- 제한 시간 내에 이미지를 확보하지 못한 플레이어에게는 서버가 미리 준비한 샘플 이미지를 자동으로 배정합니다.
- 모든 플레이어가 이미지를 확보하고 3초간 확인하면 게임이 시작됩니다.

#### 2단계: 라운드 진행

- 총 플레이어 수만큼 라운드를 진행합니다.
- 각 라운드마다 한 명씩 출제자로 지정됩니다.
- 출제자의 이미지는 이미지 준비 단계에서 미리 생성한 이미지를 사용합니다.
- 출제자는 해당 라운드에서 추측을 제출하거나 투표하지 않습니다.

라운드는 다음 3단계로 진행됩니다.

```
[1단계: 프롬프트 추측] ──> [2단계: 대혼돈의 투표] ──> [3단계: 결과 및 점수]
```

- 1단계: 프롬프트 추측
    - 출제자를 제외한 나머지 플레이어들은 출제자의 이미지를 보고, "이 이미지를 만들기 위해 어떤 프롬프트를 입력했을까?"를 추측합니다.
    - 유저들은 다른 사람들을 속이기 위해 진짜 같은 한국어 프롬프트를 제출합니다.
    - 모든 플레이어가 추측 프롬프트를 제출하면 투표 단계로 넘어갑니다.

- 2단계: 대혼돈의 투표
    - 화면에 `[출제자의 진짜 프롬프트 1개] + [플레이어들이 제출한 추측 프롬프트 N개]`가 보기로 섞여서 출력됩니다.
    - 출제자를 제외한 모두가 "이 중 진짜 프롬프트는 무엇인가?" 투표합니다.
    - 자신이 제출한 프롬프트에는 투표할 수 없습니다.

- 3단계: 결과 공개 및 점수 정산
    - 낚시 점수: 다른 유저가 내가 제출한 추측 프롬프트에 투표했다면? 낚은 사람 수 * +1점
    - 정답 점수: 진짜 프롬프트를 맞힌 사람은 각각 +2점
    - 출제자 점수: 진짜 프롬프트에 투표한 사람이 1명 이상이고, 전원이 아닌 경우 투표수 * +2점
    - 아무도 맞히지 못하거나 모두가 맞히면 출제자는 0점입니다.
    - 즉, 출제자는 너무 쉽지도 않고 너무 어렵지도 않은 프롬프트를 짜야 합니다.

#### 3단계: 최종 결과

- 모든 플레이어가 한 번씩 출제자가 되면 게임이 종료됩니다.
- 최종 점수를 공개하고, 가장 높은 점수의 플레이어가 승리합니다.

---

## 🚀 2. 시장 경쟁력 (왜 한국어 버전이 먹힐까?)

일반적인 해외 AI 게임에 한국어를 넣으면 번역기를 대충 거치기 때문에 디테일이 뭉개집니다.

- 우리 서비스는 한국어 특화로 이미지를 생성합니다.

---

## 🎯 3. 서비스 성공을 위한 핵심 엣지 (Feature)

1. 로그인 없는 간편한 시작 (익명 입장): 닉네임만 입력하고 방 만들어서 링크 공유하면 바로 시작할 수 있는 웹 기반 아키텍처 (UX 허들 최소화).
2. 한국어 프롬프트로 이미지 생성: 한국어 프롬프트로 작성자가 의도한 그림을 생성. 정확도와 속도가 중요.
3. 짤방 다운로드 및 공유: 라운드가 끝나면 `[생성된 이미지 + 정답 프롬프트 또는 베스트 추측 문구]`가 합쳐진 커스텀 카드(짤방)를 만들어 주어, 인스타그램 스토리나 커뮤니티에 쉽게 공유(바이럴)할 수 있도록 지원.
4. 수위 및 악성 필터링 (Moderation): 유저들이 실시간으로 텍스트를 마구 입력하는 파티 게임 특성상 욕설, 비하, 음란 프롬프트를 차단하는 한국어 욕설 필터링 딕셔너리와 OpenAI Moderation API를 백엔드 단에 이중 안전장치로 배치.
